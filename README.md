# beckettclarke/tap

Homebrew casks for apps by [Beckett Clarke](https://beckettclarke.ca).

```bash
brew install --cask beckettclarke/tap/bterm
```

| Cask | |
| --- | --- |
| [**bterm**](https://beckettclarke.github.io/bterm/) | A small, fast, native terminal for macOS. [Source](https://github.com/beckettclarke/bterm) |

Casks here are updated by each app's release workflow. To upgrade, run `brew upgrade --cask bterm`.
